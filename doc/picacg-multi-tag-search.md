# 哔咔原生搜索与兼容模式

在原来的搜索页选择 **picacg**，输入关键词，在搜索选项中选择排序和一个或多个分类，再执行搜索。也可以不输入关键词，只选择分类。

- 分类与关键词一起提交给哔咔的 `comics/advanced-search` 接口：`keyword`、`sort`、`categories`。
- 默认原生模式由服务端决定匹配结果及页数；不根据标签删掉返回的作品，也不会拿第一个分类替代关键词。
- 连续浏览沿用原生滚动自动加载。网络失败暂停加载，点“重试”仍请求同一页。分页浏览沿用原有页码入口。
- 分类使用现有分类页的原始名称。未选分类即普通搜索；“清除分类”保留排序。
- 搜索结果页的选项支持重新打开、取消和确认；修改后从第一页重新搜索。
- 旧版任意标签条件不会被解释成原生分类；上一版原生分类选项可以继续使用。

这不是任意详情标签的精确 AND/NOT 搜索。多选分类的匹配语义由哔咔服务端决定，本客户端不声称“必须同时命中全部分类”。

## 兼容模式：多标签筛选

在原有搜索选项中打开 **兼容模式（多标签筛选）**：

- “必须包含全部标签”：每个标签都要匹配；“排除任一标签”：匹配其中任何一个就排除。多个标签用中英文逗号、分号、顿号或换行分隔，标签内部空格会保留。
- 匹配搜索响应里的 `tags` 和 `categories`，忽略首尾空格和字母大小写，按完整标签匹配；不会按子串或自动简繁转换匹配。响应未提供的标签无法命中。
- 关键词和分类仍先发给原生接口。关键词留空且填写了包含标签时，用第一个包含标签获取候选结果；其余条件在客户端逐页筛选。只有排除条件时允许空关键词。
- 这是对候选结果的本地筛选，覆盖范围取决于原生搜索返回的候选作品，不保证找出全站所有满足标签的作品。
- 连续浏览时，首屏或后续页没有命中也会继续自动加载；填满视口后随向下滚动加载。已检查页数和找到的作品数显示在结果上方，不需要逐页点“继续筛选”。
- 网络错误会暂停，重试仍请求失败的那一页；切到其他页面或应用进入后台会暂停继续扫描，返回时恢复。已有网络请求可能完成，但不会触发后台连续翻页；退出或重新搜索后旧请求结果不会混入新结果。
- 只有服务端页数耗尽才显示整次搜索无匹配；若选择了应用的分页浏览，则保留原页码和空页上的翻页按钮。
- 关闭兼容模式会保留填写的标签，但不再应用筛选；原生分类和排序不受影响。“清除标签”只清除包含／排除条件。
- 同一个标签同时包含和排除会显示提示，并直接返回空结果，不发起无意义的扫描。

原生模式仍为默认。搜索选项关闭而未确认时不会应用修改；确认后从第一页重新搜索。
