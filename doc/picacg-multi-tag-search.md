# 哔咔多标签搜索

在搜索页选择 **picacg**，设置排序后，在“多标签搜索”中填写：

- **包含所有标签**：例如 `冒险, 彩色`，结果必须同时包含这两个标签。
- **排除任一标签**：命中任意一个排除标签的结果都会被过滤。
- 使用中英文逗号、顿号、分号或换行分隔。标签中的空格保留，例如 `Science Fiction` 是一个标签。
- 可以同时填写上方原有的关键词；也可以仅填写标签。标签胶囊可以逐个删除，“清除标签”保留排序方式。
- 结果页的“搜索选项”中可以修改这些条件。在窄屏上先点右侧更多按钮。

## 匹配与分页

标签筛选针对哔咔返回的 `tags` 和 `categories` 做精确匹配（忽略英文大小写和首尾空白），不会把标题中的某个词当成标签。

当前实现沿用哔咔的单关键词接口：有关键词时搜索关键词；无关键词且有包含标签时用第一个标签搜索候选；只有排除标签时发送空关键词。所有标签条件再逐页应用到候选结果。这里没有假设服务端支持未经验证的多标签语法，也不会预先抓取全站。

启用标签筛选后，连续浏览模式显示已筛选的**源站页数**以及“继续筛选下一页”按钮。空页也可以继续；分页模式在空页保留前后翻页入口。一次仅请求一页，避免稀疏结果触发无限自动请求。网络失败重试同一页。关闭标签筛选后恢复普通搜索的加载方式。

标签条件保留在当前搜索页面中；原有搜索历史仍保存关键词，不保存整组筛选条件。其他漫画源不启用本功能。
